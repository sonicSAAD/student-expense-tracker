# App icon and logo assets

This directory contains the source icon and logo used for the app launcher icons.

- `logo.svg` and `app_icon.svg` are the source vector marks.
- `android_*.png` and `ios_1024.png` are generated raster assets used for the platform icon sets.

Generated platform icons live in:
- `android/app/src/main/res/mipmap-*/ic_launcher.png`
- `ios/Runner/Assets.xcassets/AppIcon.appiconset/Icon-App-1024x1024@1x.png`
